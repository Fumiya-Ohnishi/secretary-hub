# AI秘書ハブ(Macローカル版)

社長が話しかけるだけで、会社の仕事(タスク・承認・資料・部署への依頼)が完結する秘書室。
顔(React + Live2D)+ 頭脳(Claude API)+ 会社(Notion / ai-company リポジトリ / Claude Code)をつなぐ。

## セットアップ(初回だけ・10分)

1. この `secretary-hub` フォルダと `ai-company` フォルダを**同じ階層**に置く
   (別の場所に置く場合は `backend/.env` の `AI_COMPANY_DIR` にフルパスを書く)
2. `backend/.env.example` をコピーして `backend/.env` にリネームし、
   `ANTHROPIC_API_KEY=sk-ant-...` に自分のキーを貼る(コンソール: console.anthropic.com)
3. **`run_mac.command` をダブルクリック** → ブラウザで http://localhost:8000 が開く
   (初回はPython仮想環境の作成で数分かかります)
4. (推奨)下の「Notion をつなぐ」でタスクと資料を Notion と同期

## 使い方(話しかけるだけで完結)

秘書に話しかけると、秘書が道具を使って実際に仕事を進めます。画面は話の内容に合わせて切り替わります。

| 話しかけ方の例 | 秘書がすること |
|---|---|
| 「今日の報告をして」 | 収益・承認待ち・期限切れをまとめて報告 |
| 「承認待ちを見せて」「T-009 を承認したい」 | 承認カードを出す →「はい」で承認 /「差し戻し、〇〇を直して」で差し戻し |
| 「企画書を開いて要約して」 | Notion の資料を右に開き、要点を話す |
| 「T-015 を進行中にして」「〇〇をタスクに追加して」 | Notion のタスクを更新・起票 |
| 「戦略部に来週の投稿企画を頼んで」 | タスクを起票し、裏で Claude Code が ai-company で作業。終わると秘書が報告 |
| 「今週の投稿を見せて」 | 投稿タブに投稿セット(台本・キャプション・画像)を出し、承認カードを出す。「はい」で全部承認 |
| 「今日 note が500円売れた」「インスタのフォロワー120人」 | 収益(revenue.csv と Notion の収益DB)・フォロワー数(followers.csv)を記録し、ホームのグラフに反映 |
| 「インスタ作ったよ、URLは https://www.instagram.com/〜」 | アカウント台帳(data/accounts.md と Notion「アカウント台帳」)に URL を記録。**パスワードは言わないでください** |
| 「週次レポートを作って」 | 数字とタスクから reports/weekly_YYYY-WW.md を作り、Notion にも保存して資料タブに開く |
| 「T-014 の期限を来週金曜にして」 | タスクの期限を変更(画面では日付をクリックして変更) |

- **起動時の報告**: 開くと秘書が収益・タスク・投稿の状況と「本日のおすすめ」をまとめます(最初に画面をクリックすると読み上げ)
- **投稿タブ**: 部署が作った週の投稿セットを読み、投稿ごとに承認 / 差し戻し(理由つき)/ 投稿しました を付ける。キャプションはコピーボタンで貼り付け用にコピー
- 会話はブラウザに残るので、再読み込みしても秘書は直前の話を覚えています。部署の作業履歴とAI利用料は `backend/data/` に保存(git には入りません)
- **投稿アシスタント**: 「今日の投稿を始めて」(または左下「投稿を始める」)で、承認済みの投稿を1件ずつ案内。
  キャプションのコピー → 画像の保存 → チェックリスト →「投稿しました」で投稿済みを記録
- **返事が速い**: 秘書は書いた先から1文ずつ読み上げます(VOICEVOX は次の文の音声を先に作っておく)
- **予定タブ**: 週のカレンダーに投稿予定・タスクの期限・部署の作業を表示。投稿とタスクはつまんで別の日へ移せます
- **組織図タブ**: 部署と社員(ai-company/.claude/agents/)と、いま作業中の部署を表示
- **呼びかけモード**(⚙ 声・設定): ハンズフリー中は「セナ、〜」と名前を呼んだときだけ反応(テレビや雑談に反応しない)
- **キー操作**: スペースを押している間だけ聞き取り / ⌘K(Ctrl+K)でタスク・投稿・資料・作業・会話をまとめて検索 / Esc で閉じる
- **接続の診断**: 上部の丸い表示を押すと、頭脳・Notion・VOICEVOX・Claude Code などの状態と直し方を表示
- **秘書の演出**: 背景が時間帯(朝・昼・夕方・夜)で変わり、目線がマウスを追います。しばらく操作がないと、判断待ちや投稿待ちがあるときだけ声をかけます(15分ごと・最大3回)
- **定時チェック**(⚙ でオン/オフ。既定 9:00・12:00・17:00): 秘書ハブが起動している間、秘書が自分で状況を確認し、
  「今日やること」・遅れ・社長へのお願いを知らせます(画面で読み上げ+Mac の通知センター)。逆算プランの次の工程も自動で部署に依頼します
- **逆算スケジュール**: 「来週金曜の投稿に向けて逆算して進めて」と話しかけると、企画→台本→仕上げ→社長の承認の工程を日付つきで起票。
  部署の工程は、前の工程が終わると秘書が自動で依頼します(社長の工程は自動では進みません)
- **作るAIとチェックするAI**: 企画部・制作部の作業は、メディア部(チェック役)が就業規則・プレイブックと照合して直してから承認待ちに回ります
- **修正ログ → ルール化**: 社長の差し戻し理由は ai-company/data/corrections.md に自動で残ります。同じ指摘が繰り返されると、
  秘書がルール案を出します。承認すると playbooks/learned_rules.md に追加され、全部署が作業前に読みます
- **ハンズフリー**(入力欄の右のボタン): 秘書が話し終わると自動で聞き取りを再開します。マイクを押さずに会話が続きます
- 承認・差し戻しは**社長の操作(ボタンか「はい」の返事)でだけ**確定します。秘書が勝手に承認することはありません(就業規則)
- 部署への依頼には Claude Code が必要です(ターミナルで `npm install -g @anthropic-ai/claude-code` → `claude` で一度ログイン)

## 画面の見方

- 左: 秘書(Live2D)。下の枠に秘書のセリフ。右上に「聞いています/考えています/話しています」
- 右のタブ
  - **ホーム**: 今月の収益(目標5万)・承認待ち・未完了・期限切れ、社長の判断待ち、進めている仕事、部署の作業、フォロワーと収益のグラフ、今月のAI利用料(概算)
  - **投稿**: 週の投稿セット(台本・キャプション・画像)。承認・差し戻し・投稿済み
  - **タスク**: Notion のタスク一覧。状態の変更・起票・承認/差し戻しがここでもできる
  - **資料**: Notion の資料を読む(企画書・アカウント設計など)
  - **部署の作業**: 部署(Claude Code)への依頼と結果
  - **会話**: これまでの会話
- 上の丸い表示: 頭脳(API キー)・Notion・部署(Claude Code)・声(VOICEVOX)の接続状態
- ⚙: 読み上げのオン/オフ、ハンズフリー、声の選択

## Notion をつなぐ(初回だけ・5分)

タスクと資料を Notion と同期します。つなぐまでは ai-company/data/tasks.md(控え)で動きます。

1. https://www.notion.so/profile/integrations を開き「新しいインテグレーション」
   - 名前: `秘書ハブ` / 種類: 内部(Internal)/ ワークスペース: AI会社のあるもの → 保存
2. 「内部インテグレーションシークレット」を表示してコピー
3. `backend/.env` に1行追加: `NOTION_TOKEN=コピーした値`(**チャットには貼らないでください**)
4. Notion で「AI会社」ページを開き、右上「•••」→「接続」→「秘書ハブ」を選ぶ
   (AI会社の下のページ・タスクDBにも自動で権限が付きます)
5. 秘書ハブを再起動(ターミナルで Ctrl+C → `run_mac.command` をダブルクリック)

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| 会社データが「見つかりません」 | `backend/.env` の `AI_COMPANY_DIR` に ai-company のフルパスを設定 |
| 音声入力が効かない | Chrome または Safari で開く(Brave は不可)。マイク権限を許可 |
| 上の表示が「部署 未接続」 | ターミナルで `claude --version` が通るか確認。なければ npm install -g |
| 「Notion 未接続」のまま | `.env` の `NOTION_TOKEN` を確認して再起動。資料タブに手順あり |
| Notion エラー(404) | Notion の「AI会社」ページにインテグレーション「秘書ハブ」を接続 |
| 「モデルが使えません」 | `.env` の `ANTHROPIC_MODEL` を `claude-opus-5-5` にする(行を消しても既定でこれ) |
| APIキーを変えたい | `backend/.env` を編集して再起動 |

## セキュリティ

- APIキー・Notion のシークレットは `backend/.env` のみ(gitコミット禁止)。ブラウザ側には渡しません
- サーバーはこの Mac の中だけで開きます(localhost)。同じ Wi-Fi の他の端末からは見えません
- パスワード類はこのシステムでは一切扱いません(投稿は社長が実行)


## リールの自動制作

Live2D の秘書 + VOICEVOX の声 + テロップで、縦長のリール(1080×1920・MP4)を自動で作る。

### 初回だけ(Mac)
```bash
brew install ffmpeg
```
```bash
cd ~/secretary-hub/tools/reel && npm install
```
(Google Chrome を使うので、ブラウザの追加ダウンロードは不要)

### 作り方
秘書ハブと VOICEVOX を起動した状態で:
```bash
node ~/secretary-hub/tools/reel/render_reel.mjs <台本.json> <出力.mp4>
```
- 台本の形式: ai-company の `playbooks/reel_format.md`(見本: `brand/samples/reel_sample_B.json`)
- 映像制作部に頼めば、部署が台本を書いて書き出しまで行う(秘書ハブが部署にこのコマンドだけを許可している)
- 見た目は3テーマ(A ライト / B ダーク / C ノート)。安全範囲・「※AIの秘書キャラクターです」・VOICEVOX のクレジットは自動で入る
- 仕組み: `frontend/reel.html`(リール制作スタジオ)を Chrome で開き、1コマずつ描いて録画 → ffmpeg で声と合わせる

## Live2D の秘書

左の秘書は Live2D モデルで動きます(自動まばたき・呼吸、話すと口パク、気分で表情が変わる)。
読み込めない場合は、従来の静止画(`frontend/public/faces/`)に自動で切り替わります。

| 気分 | 表情 | いつ変わるか |
|---|---|---|
| normal | 通常 | ふだん |
| pleased | 上機嫌(笑い目・頬染め) | 褒めたとき・お礼を言ったとき |
| thinking | 考え中(困り眉) | 部署に作業を頼んだとき・考えているとき |
| pouty | 不機嫌(軽) | 無理を言ったとき・からかったとき |

### 初回だけ: Cubism Core を置く

Live2D の表示には Live2D 公式の実行用ファイル **Cubism Core** が必要です。ライセンス上、このリポジトリ(公開)には含めていません。

1. Live2D 公式サイトの「Cubism SDK for Web」をダウンロード(利用規約に同意)
2. zip の中の `Core/live2dcubismcore.js` を `frontend/public/live2d/core/live2dcubismcore.js` に置く
3. `run_mac.command` をダブルクリック(画面が自動でビルドし直されます)

### 声と音声入力

**おすすめ: VOICEVOX の声で話す(無料)**

[VOICEVOX](https://voicevox.hiroshiba.jp/) は無料の日本語読み上げソフトです(商用利用も可。キャラクターごとの規約あり)。
起動しておくと、秘書はその声で話し、**声の大きさに合わせて口が動きます**。

1. VOICEVOX 公式サイトから Mac 版をダウンロードしてインストール
2. VOICEVOX を起動したまま、秘書ハブを開く(画面を再読み込み)
3. 画面右上の ⚙ から声を選ぶ(既定は「冥鳴ひまり」。選んだ声は次回も使われます)

- 既定の声は `backend/.env` の `VOICEVOX_SPEAKER=声の名前の一部` で変えられます
- 秘書ハブ内で聞くだけならクレジット表記は不要です。作った音声を SNS などに出す場合は「VOICEVOX:キャラ名」の表記が必要です(各キャラクターの規約を確認)

**VOICEVOX が起動していないとき**は、Mac に入っている日本語の女性の声(O-ren → Kyoko の順)で話します。
Mac の「システム設定 → アクセシビリティ → 読み上げコンテンツ → システムの声 → 声を管理」で
**Kyoko(拡張)** や **O-ren(プレミアム)** を追加すると、少し自然になります。

**音声入力(🎙)**は **Chrome か Safari** で使えます。Brave では使えません(認識サーバーに繋がらないため)。
