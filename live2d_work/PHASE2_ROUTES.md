  ※ Claude の作業環境から live2d.com の比較ページにアクセスできず最新の上限値を再確認できていない。インストール時に社長側で [公式比較ページ](https://www.live2d.com/en/cubism/comparison/) を一度確認してください(上限を超えると保存・書き出しできなくなる仕様)

### 見積もり依頼文(下書き)

> はじめまして。Live2Dモデリングのみ(PSD持ち込み)のお見積もりをお願いします。
> - 素材: AI生成イラストを AIツールでパーツ分けしたPSD(バストアップ、約25レイヤー)。※AI生成である点をご了承いただける方を希望します
> - 用途: 自社内のPCアプリで表示する秘書キャラクター(配信・販売はしません)
> - 必要な動き: まばたき(左右別)、口パク(開閉+口の形)、呼吸、顔の向き(左右・上下・傾き)、髪揺れ(物理演算)
> - 表情: 4種(通常/上機嫌/考え中/不機嫌)を exp3.json で
> - 納品形式: Cubism 4以降の書き出し一式(.moc3 / .model3.json / テクスチャ / .physics3.json / .exp3.json)+ .cmo3
> - パラメータIDは Live2D 標準ID(ParamEyeLOpen 等)でお願いします
> - 希望納期と、修正回数をお知らせください

※ AI生成素材の持ち込みを断る出品者もいるため、依頼文で明記している(会社規則「AIで作ったことを隠さない」にも合致)。

## 共通の納品仕様(Phase 3 で読み込むための約束)

```
secretary-hub/frontend/public/live2d/secretary/
  secretary.model3.json      ← これを読み込む
  secretary.moc3
  secretary.2048/texture_00.png
  secretary.physics3.json    (任意)
  expressions/normal.exp3.json
  expressions/pleased.exp3.json
  expressions/thinking.exp3.json
  expressions/pouty.exp3.json
```

- `model3.json` の `Groups` に `EyeBlink`(ParamEyeLOpen, ParamEyeROpen)と `LipSync`(ParamMouthOpenY)を定義する
  → 自動まばたきと口パクはアプリ側(pixi-live2d-display)で動かすので、モーションファイルは不要
- 表情名は `normal / pleased / thinking / pouty`(現行の気分ステートと同じ名前)
- 呼吸は `ParamBreath` を使う(アプリ側で自動的に揺らす)
